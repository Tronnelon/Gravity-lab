# Utvikling av Gravity Lab

- Bruk norsk i dialog med brukeren. Behold Gravity Lab som produktnavn.
- Sjekk gjeldende versjon og funksjonalitet i kildekoden før du endrer eller dokumenterer dem. Sjekk åpne pull requests for pågående arbeid.
- Behold en vitenskapelig troverdig fysikkmotor. Visuelle forenklinger kan endre presentasjonen, mens beregningene skal følge den valgte fysiske modellen. Forklar simuleringsenheter, antakelser og forenklinger der de har betydning.
- Prioriter enkel betjening med berøring og mus, diskret grafikk og stabil ytelse på iPhone og Mac. Bevar frakoblet PWA-bruk og unngå unødvendige avhengigheter.
- Bevar eksisterende funksjonalitet ved endringer. Test relevante brukerflyter, inkludert frakoblet bruk når service workeren eller bufrede ressurser endres. Oppgi hvilke enheter og nettlesere som faktisk er testet.
- Oppdater appversjonen og service workerens cache ved nye utgivelser. Sørg for at ressurser som trengs frakoblet, følger med i cachen.
- Lever avgrensede endringer trinnvis gjennom pull requests for brukerens gjennomgang. Dokumenter status og eventuelle gjenværende tester.
- For astronomiske systemer, oppgi kilder og usikkerhet. Skill observerte parametere fra antatte startbetingelser. Presenter statistikk fra simuleringer som simuleringsresultater.
